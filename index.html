📖 Как пользоваться приложением

🌤️ Погода на маршруте

  • Блок погоды показывает текущие условия и прогноз на 5 дней
  • Погода автоматически обновляется при перемещении карты
  • Кнопка «🔄 Обновить» позволяет обновить данные вручную
  • Координаты для прогноза берутся из центра карты

🗺️ Карта маршрута

  • Двойной клик на карте — добавить точка (с Shift – быстро)
  • 📍 Геолокация — найти ваше текущее местоположение
  • 🔍 Поиск адреса — найти место по адресу
  • Клик на маркере — выделить точку
  • ПКМ (правая кнопка) — меню действий
  • Перетаскивание маркера — изменить позицию
  • 📥 Импорт KML/GPX/TCX — загрузить маршрут из файла

📋 Шаблоны походов

  • Сохраните текущий поход как шаблон для повторного использования
  • Загрузите шаблон из файла (.json)
  • Дублируйте поход для создания похожего

✅ Чек-лист сборов

  • Отмечайте предметы галочками по мере сбора
  • Прогресс-бар покажет % готовности
  • Кнопка «⚠️ Показать несобранное критичное» — что важно не забыть

🔗 Совместный доступ

  1. Нажмите «🔗 Создать ссылку»
  2. Выберите режим: редактирование или только чтение
  3. Отправьте ссылку участникам

👤 Роли в группе

  • При добавлении участника можно выбрать роль (👑 Лидер, 🗺️ Навигатор, 🍳 Повар и т.д.)
  • Роль можно изменить или добавить позже через кнопку ✏️ рядом с именем
  • Выберите ✨ Свой вариант..., чтобы ввести уникальную роль вручную

⚖️ Оптимизатор нагрузки

  • Установите лимиты веса для каждого участника
  • Нажмите «🔍 Анализировать нагрузку»
  • Приложение покажет кто перегружен и предложит перераспределить вещи
  • Подсказки помогут равномерно распределить снаряжение

🎒 Добавление снаряжения

  1. Введите название предмета (например, «Палатка»)
  2. Выберите категорию (Снаряжение, Еда, Кухня и т.д.)
  3. Укажите вес и цену
  4. Выберите владельца из списка участников
  5. Отметьте 🔥 если предмет критично важен
  6. Нажмите «➕ Добавить»

💰 Учёт расходов

  1. В разделе «Расходы» введите описание покупки
  2. Укажите сумму и категорию
  3. Выберите кто оплатил
  4. Приложение автоматически рассчитает, кто кому должен

📊 Графики и статистика

  • Автоматически строятся диаграммы по нагрузке участников и тратам
  • Показаны детальные списки весов и сумм
  • Можно свернуть/развернуть графики для экономии места

📝 Отчет после похода

  • Заполните поля План vs Факт (км, дни, бюджет)
  • Оцените снаряжение и оставьте заметки
  • Сохраните отчет или экспортируйте в текстовый файл

⌨️ Горячие клавиши

  • Ctrl+Z — отменить последнее действие
  • Ctrl+S — сохранить (автосохранение каждые 0.5 сек)

💾 Экспорт и импорт

  • Нажмите «☰ Меню» в верхней панели
  • Выберите формат данных (JSON/TXT/CSV) или маршрутов (GPX/KML/TCX)
  • Нажмите Экспорт или Импорт

🖥️ Управление видимостью разделов

  • Нажмите кнопку «🖥️ Фильтры экрана» в верхней панели
  • Отметьте галочками разделы, которые хотите видеть на экране
  • Снимите галочки, чтобы скрыть ненужные разделы
  • Порядок чекбоксов соответствует расположению блоков на странице

🌐 Офлайн-работа

Приложение работает без интернета! Все данные сохраняются в браузере. Индикатор в правом нижнем углу покажет статус подключения.
