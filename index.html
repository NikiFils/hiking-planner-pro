📖 Как пользоваться приложением

🎒 Добавление снаряжения

  1. Введите название предмета (например, «Палатка»)
  2. Выберите категорию (Снаряжение, Еда, Кухня и т.д.)
  3. Укажите вес и цену
  4. Выберите владельца из списка участников
  5. Отметьте 🔥 если предмет критично важен
  6. Нажмите «➕ Добавить»

💰 Учёт расходов

  1. В разделе «Расходы» введите описание покупки
  2. Укажите сумму и категорию
  3. Выберите кто оплатил
  4. Приложение автоматически рассчитает, кто кому должен

🗺️ Карта маршрута

  • Двойной клик на карте — добавить точку
  • Клик на маркере — выделить точку
  • ПКМ (правая кнопка) — меню действий
  • Перетаскивание маркера — изменить позицию

✅ Чек-лист сборов

  • Отмечайте предметы галочками по мере сбора
  • Прогресс-бар покажет % готовности
  • Кнопка «⚠️ Показать несобранное критичное» — что важно не забыть

📋 Шаблоны походов

  • Сохраните текущий поход как шаблон для повторного использования
  • Загрузите шаблон из файла (.json)
  • Дублируйте поход для создания похожего

🔗 Совместный доступ

  1. Нажмите «🔗 Создать ссылку»
  2. Выберите режим: редактирование или только чтение
  3. Отправьте ссылку участникам

⌨️ Горячие клавиши

  • Ctrl+Z — отменить последнее действие
  • Ctrl+S — сохранить (автосохранение каждые 0.5 сек)

💾 Экспорт и импорт

  • Нажмите «☰ Меню» в верхней панели
  • Отметьте галочками что экспортировать (Всё, Снаряжение, Траты)
  • Выберите формат и нажмите Экспорт или Импорт

🖥️ Управление видимостью разделов

  • Нажмите кнопку «🖥️ Фильтры экрана» в верхней панели
  • Отметьте галочками разделы, которые хотите видеть на экране
  • Снимите галочки, чтобы скрыть ненужные разделы

🌐 Офлайн-работа

Приложение работает без интернета! Все данные сохраняются в браузере. Индикатор в правом нижнем углу покажет статус подключения.
